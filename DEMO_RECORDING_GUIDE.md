# Demo recording guide (for the owner)

Goal: one short, honest video showing the app physically controlling the
mouse. 30–60 seconds is plenty. One continuous shot if you can manage it.

## Setup

- Tablet: Samsung Galaxy Tab A9+ (the verified environment) — or any device
  you have
- Mouse: Logitech G102 LIGHTSYNC connected via USB OTG
- Lighting: bright enough that the mouse LEDs read clearly on camera. A dark
  room works well for RGB, but keep the tablet screen readable
- Camera: stable — prop the phone or use a stand. Avoid holding it by hand
  if possible
- Clean notifications: enable Do Not Disturb before recording so no personal
  messages pop up on camera
- Close personal apps; only the G102 Controller app should be open

## Suggested sequence (30–60 seconds)

| Time | Shot |
|------|------|
| 0–5 s | Wide shot: tablet + physical G102 connected via OTG. Mouse LEDs visible |
| 5–10 s | Tap to open the app (portrait). Show it detects the device |
| 10–15 s | Press **RGB OFF** — show the mouse lighting physically turn off |
| 15–20 s | Press **RGB ON** — lighting returns |
| 20–30 s | Pick a vivid color (red), **APPLY COLOR** — show physical result |
| 30–40 s | Pick one or two effects (Cycle, Wave) — **APPLY** — show physical result |
| 40–50 s | Rotate to landscape, show the responsive interface |
| 50–60 s | Optional closing: wide shot of mouse running the effect |

## Tips

- Frame BOTH the tablet screen and the mouse in the same shot when showing
  cause-and-effect (tap → LEDs change). That's the whole proof
- One continuous take beats fancy editing. Do not heavily edit
- If a take fails, just re-record; don't cut mid-action
- Portrait is the primary tested orientation — keep the main flow in
  portrait
- No voiceover needed; caption text over the video works if you want

## After recording

- Name: `demo.mp4`
- Where: attach to the public GitHub Release (owner action), or link from
  README once uploaded
- Verify no personal info is visible (notifications, other apps, emails)
  before publishing
