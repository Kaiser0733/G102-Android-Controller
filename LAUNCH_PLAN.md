# Launch plan

Goal for the first weeks: **real users + real compatibility data** — not
hype. Everything below is owner-actionable; nothing is automated spam.

## Ready-state checklist

- [ ] Public release published (after owner review of the draft)
- [ ] Demo video attached (owner records per DEMO_RECORDING_GUIDE.md)
- [ ] Screenshots attached (owner, real device)
- [ ] Compatibility matrix seeded with the verified G102 row
- [ ] Issue templates live

## Day 1

- Publish the GitHub Release (owner approves the draft)
- Pin the repository: short description + demo video link
- Nothing else. Let it breathe

## Day 2–3

- One Reddit post, chosen community at a time (r/LogitechG, r/MechanicalKeyboards
  adjacent subs, or r/androidapps — pick the single best fit):
  - genuine technical explanation: how Android USB Host + HID++ control
    transfers drive LIGHTSYNC lighting, no root, no PC
  - what's verified (G102 on a Tab A9+) and what isn't (G203 expected)
  - link the repo, not a hype thread
- Tone: "I built this, here's how it works, here's exactly what's tested."

## Week 2+

- Share genuine compatibility reports as they arrive (GitHub issues →
  COMPATIBILITY.md rows)
- X post with the demo video once it exists (short, factual)
- Android enthusiast communities (XDA etc.) only if a natural thread exists

## Standing rules

- Never claim untested compatibility
- Never claim Logitech affiliation
- No astroturfing, no vote manipulation, no repost spam — one honest post
  per community
- Priority: issue tracker quality over follower count. Every hardware
  report becomes a COMPATIBILITY.md row with evidence
